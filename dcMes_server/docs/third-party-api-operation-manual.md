# 第三方接口管理 — 操作说明

> 适用人员：业务/运营人员
> 模块路径：系统菜单 → 第三方接口管理

---

## 一、模块概览

| 功能页面 | 入口 | 用途 |
|---------|------|------|
| 接口配置管理 | 主菜单 | 维护第三方接口的基本信息（地址、方法、状态） |
| 参数模板管理 | 接口配置行 → 参数模板（抽屉） | 为指定接口保存常用参数组合 |
| 请求日志 | 接口配置行 → 请求日志（抽屉） | 查看该接口的历史调用记录 |
| 全量请求日志 | 独立菜单页 | 查看所有接口的调用记录 |

---

## 二、接口配置管理

### 2.1 查看接口列表

进入「接口配置管理」页面，支持按以下条件筛选：

- **接口名称**：模糊匹配
- **接口地址**：模糊匹配
- **状态**：启用 / 禁用 / 作废
- **创建时间**：日期范围

### 2.2 新增接口

1. 点击「**新增接口**」按钮
2. 填写以下信息：

   | 字段 | 说明 | 是否必填 |
   |------|------|--------|
   | 接口名称 | 用于标识，系统内唯一 | ✅ |
   | 接口地址 | 完整 URL（含 http/https） | ✅ |
   | 请求方式 | GET / POST / PUT / DELETE | ✅ |
   | 描述 | 接口用途说明 | ❌ |
   | 初始状态 | 默认"启用" | ✅ |

3. 点击「**确定**」保存

> ⚠️ 接口名称不可重复，URL 格式必须以 `http://` 或 `https://` 开头。

### 2.3 编辑接口

- 点击操作列「**编辑**」按钮
- **已作废的接口不允许编辑**
- 若修改了接口地址或请求方式，系统会提示"核心信息变更，现有参数模板可能无法正常使用"

### 2.4 状态切换

接口支持三种状态，可在列表操作栏或编辑弹窗中切换：

| 状态 | 含义 | 是否可调用 |
|------|------|---------|
| 启用（绿色） | 正常使用 | ✅ 可调用 |
| 禁用（橙色） | 暂停使用 | ❌ 不可调用 |
| 作废（灰色） | 永久下线 | ❌ 不可调用，且不可编辑 |

### 2.5 删除接口

- 点击「**删除**」并二次确认
- 删除后：该接口的**参数模板**和**文件记录**一并删除；**历史调用日志保留**（接口关联置空，日志可查但不可重新调用）

---

## 三、参数模板管理

点击接口配置行的「**参数模板**」按钮，在右侧抽屉中管理该接口的参数模板。

### 3.1 模板用途

将常用的参数键值对保存为模板，下次调用接口时直接选模板，一键填充参数，无需重复输入。

### 3.2 新增模板

1. 点击抽屉内「**新增模板**」
2. 填写模板名称、参数类型（见下表）、参数列表（Key/Value）
3. 保存

| 参数类型 | 发送方式 |
|---------|---------|
| Query | 拼接到 URL 查询字符串（?key=value） |
| Body form-data | 以 multipart/form-data 格式放在请求体 |
| Body urlencoded | 以 application/x-www-form-urlencoded 格式放在请求体 |

### 3.3 其他操作

| 操作 | 说明 |
|------|------|
| **编辑** | 修改模板名称或参数内容 |
| **删除 / 批量删除** | 删除后不影响历史日志中的参数快照 |
| **拖拽排序** | 拖动行左侧图标调整模板顺序 |
| **操作记录** | 查看该模板的新增/编辑/删除历史 |
| **用选中模板调用** | 选中某条模板后直接发起接口调用 |

---

## 四、调用接口

点击接口配置行的「**调用接口**」按钮（仅"启用"状态可点击），弹出调用窗口。

### 4.1 自定义参数模式

1. 选择参数类型（Query / Body form-data / Body urlencoded）
2. 可在"选择参数模板"下拉框中选一个模板，自动填充参数
3. 手动调整 Key/Value 参数列表
4. 点击「**调用**」发起请求
5. 响应结果显示在下方（响应体 / 响应头，支持复制）
6. 如需保存当前参数为模板，点击「**保存为模板**」

### 4.2 文件调用模式

1. 切换到「**文件调用**」标签
2. 拖拽或点击选择文件（大小限制 20MB）
3. 也可点击「最近上传记录」中的历史文件直接复用（无需重新上传）
4. 点击「**调用**」发起请求
5. 文件会保存到服务器，可在日志中下载

> 💡 每个接口最多保留最近 **3 条**文件上传记录。

---

## 五、请求日志（接口维度）

点击接口配置行的「**请求日志**」按钮，在右侧抽屉中查看该接口的历史调用记录。

- 支持按**状态**（成功/失败）、**调用方式**、**时间范围**筛选
- 点击「**详情**」查看单条日志的完整请求参数和响应内容
- 点击「**重试**」对失败日志重新发送（参数/文件均沿用原始数据）
- 文件调用日志无论成功失败，均可点击「**重新发送**」使用服务器上已存的文件再次发送

---

## 六、全量请求日志管理页

> 入口：菜单 → 第三方接口管理 → 请求日志

### 6.1 查询

支持多条件组合查询：响应状态、调用方式、参数模板名、时间范围。

### 6.2 操作

| 按钮 | 说明 |
|------|------|
| **详情** | 查看完整的请求/响应信息 |
| **重试** | 对失败日志重新发送（参数/文件沿用原始数据） |
| **重新发送** | 文件调用日志专属，用服务器存储的文件再次发送 |
| **重新调用** | 打开调用窗口，可修改参数后重新发送（参数模式回显历史参数） |

### 6.3 日志详情页

- 展示接口快照（调用时的接口地址/方法）、请求参数/文件信息、响应体、响应头
- 文件调用日志可直接**下载原始文件**
- 可从详情页直接发起「**重试**」或「**重新调用**」

---

## 七、注意事项

1. **"禁用"接口**的历史模板保留，但调用功能不可用；恢复"启用"后可继续使用。
2. **"作废"接口**不可编辑、不可调用，也无法新增模板；历史日志的重新调用功能也会失效。
3. **文件保留策略**：每个接口仅保留最近 3 次上传的文件，超出后自动从服务器删除最旧的。若文件已被清理，文件调用重试将失败，需重新上传。
4. 所有调用操作均会自动记录日志，包含调用人信息，完整可追溯。
