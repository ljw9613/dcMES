# 追觅三元组管理 — 简易操作手册

面向车间管理员与对接开发人员，说明「三元组导入 → SN 绑定规则（可选）→ 对外绑定/查询」的基本操作。

---

## 一、进入页面

1. 使用浏览器登录 MES 管理端。
2. 在左侧菜单中打开 **追觅三元组管理**（若看不到菜单，需由系统管理员在「菜单管理」中为您的角色分配该菜单；页面组件路径为 `/tripletData/index`）。

---

## 二、导入三元组（DID / KEY / MAC 等）

1. 点击 **下载导入模板**，得到 Excel 模板。
2. 按表头填写：**DID、KEY、MAC、TimeArea、Language**（与模板示例一致即可）。
3. MAC 建议使用 **冒号分隔的大写十六进制**，例如：`10:06:48:A9:3E:EF`。
4. 点击 **导入三元组**，选择填好的 Excel 文件。
5. 导入结束后会弹出结果：**成功条数**；若有失败行，会列出 **行号、错误码、说明**（常见为与库内或文件内重复的 DID / KEY / MAC，或格式错误）。

说明：导入成功的记录在系统中为 **未绑定** 状态，等待后续通过对外接口用 SN 领取绑定。

---

## 三、配置 SN 绑定校验规则（可选）

若需要在绑定 SN 时校验 SN 格式是否符合某条 **条码匹配规则**（与「条码规则」模块中的 `barcodeRule` 一致）：

1. 点击 **SN 绑定校验规则**，打开配置弹窗。
2. **启用校验**：打开后，且已选择下方规则时，对外绑定接口才会按规则校验 SN。
3. **条码匹配规则**：从下拉列表中选择一条已 **启用** 的规则（仅展示启用规则）。
4. 弹窗中会显示 **服务端当前** 已保存的规则摘要；修改后点击 **保存配置**。
5. **重新加载** 可从服务器再次拉取配置与规则列表（多人协作时可避免界面过期）。

说明：绑定接口侧 **只执行规则中的「校验」配置**（如长度、截取、正则等），**不执行提取配置、也不比对物料**，与产线扫码里完整的条码校验逻辑有所区别。

---

## 四、SN 绑定时自动关联工单

当追觅侧调用 `type=1` 绑定接口时，系统会额外执行以下逻辑：

1. 以传入的 **SN** 在 **主条码工艺流程表**（`material_process_flow`）中查询 `barcode` 字段。
2. 若查询到对应的流程记录，且该记录关联了 **工单**（`productionPlanWorkOrderId`），则自动将工单 ID 及工单号（`workOrderNo`）一并写入三元组记录。
3. 若 flow 表中不存在该 SN，则工单字段留空，**不影响绑定流程正常完成**。

绑定后，可在列表的 **绑定工单号** 列中直接查看该三元组对应的生产工单。

---

## 五、列表查询

在页面上方可按 **DID、MAC、SN、状态（未绑定/已绑定）** 筛选，分页查看三元组列表。列表包含 **绑定工单号** 列，已绑定且关联工单的记录会直接展示工单号；未关联则显示「—」。

---

## 六、对外接口测试（管理端自测）

1. 点击 **对外接口测试**，打开弹窗。
2. 填写 **sn**、**type**（`1` = 绑定领取三元组，`2` = 按 SN 查询已绑定结果）。
3. 点击 **发送请求**：请求 **不携带登录 Token**，与追觅设备侧调用方式一致（请确保浏览器能访问后端地址；生产环境注意跨域与网络策略）。

正式对接时，追觅侧应调用同一地址，例如：

- 路径：`POST /api/v1/tripletData`
- `Content-Type: application/json`
- 请求体示例：`{ "sn": "SN123456789", "type": "1" }`

业务成功时返回 `code: "SUCCESS"` 及 `data` 中的 `did、key、mac` 等；失败时 HTTP 多为 200，通过 `code` 区分（如 `PARAM_ERROR`、`DUPLICATE_SN`、`NO_AVAILABLE_TRIPLET` 等）。具体错误码以接口文档为准。

**安全提示**：该绑定接口在系统中配置为 **免登录白名单**，依赖 **内网或专线隔离**，请勿对公网直接暴露。

---

## 七、典型流程小结

| 步骤 | 操作 |
|------|------|
| 1 | 下载模板 → 填写 DID/KEY/MAC/TimeArea/Language → 导入 |
| 2 | （可选）打开「SN 绑定校验规则」→ 选规则并启用校验 → 保存 |
| 3 | 追觅侧对每条设备 SN 调用 `type=1` 绑定；系统自动查 flow 表，若 SN 存在则关联对应工单 |
| 4 | 绑定成功后，MES 列表「绑定工单号」列可直接查看关联工单 |
| 5 | 需要复核时，可用 `type=2` 按 SN 查询已绑定数据，或在 MES 列表中筛选查看 |

## 八、常见问题

**Q：导入提示 DID/KEY/MAC 已存在？**  
A：同一值在全库必须唯一，请检查是否重复导入或 Excel 内有重复行。

**Q：绑定接口提示暂无可用三元组？**  
A：表示当前没有「未绑定」的库存，需先导入新的三元组。

**Q：启用校验后绑定总失败？**  
A：检查所选条码规则是否仍为「启用」状态，以及 SN 是否满足规则中的长度/正则/截取等条件。

**Q：菜单里没有「追觅三元组管理」？**  
A：联系管理员在菜单管理中新增菜单项，`component` 填写 `/tripletData/index`，并为角色授权。
